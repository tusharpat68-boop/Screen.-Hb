# স্ক্রিন রেকর্ডার (Android)

সহজ স্ক্রিন রেকর্ডার: যেকোনো ওয়েবসাইট/ভিডিও/অ্যাপের স্ক্রিন + মাইক্রোফোনের ভয়েসসহ MP4 রেকর্ড করে।
ভিডিও সেভ হয়: `Movies/ScreenRecorder` (গ্যালারিতে দেখা যাবে)। Android 10+ দরকার। কোনো বিজ্ঞাপন/ওয়াটারমার্ক নেই।

## APK বানানোর সহজ উপায় (ফোন থেকেই, কম্পিউটার ছাড়া)
1. GitHub-এ একটা নতুন repo খুলুন।
2. এই ফোল্ডারের সব ফাইল (লুকানো `.github` ফোল্ডারসহ) repo-তে আপলোড করুন।
3. repo-র **Actions** ট্যাবে "Build APK" নিজে চলবে (না চললে Run workflow চাপুন)।
4. শেষ হলে ওই run খুলে **ScreenRecorder-APK** artifact নামিয়ে zip খুলুন → `app-debug.apk` ইনস্টল করুন।

## Android Studio / Termux-এ বানাতে
`gradle assembleDebug` (Gradle 8.9+, JDK 17, Android SDK 34 লাগবে)।
APK: `app/build/outputs/apk/debug/app-debug.apk`

## ব্যবহার
1. অ্যাপ খুলে "রেকর্ড শুরু করুন" চাপুন → মাইক ও নোটিফিকেশনের অনুমতি দিন → "Start now" চাপুন।
2. অ্যাপ পেছনে চলে যাবে; ব্রাউজার/ভিডিও খুলে যা খুশি রেকর্ড করুন।
3. থামাতে নোটিফিকেশন নামিয়ে "বন্ধ করুন" চাপুন।

## সাউন্ড অপশন
- **ফোনের ভেতরের সাউন্ড**: ব্রাউজার/ভিডিও/গেমের সাউন্ড সরাসরি রেকর্ড হয় (Android 10+)।
- **মাইক**: আপনার ভয়েস। দুটো একসাথে চালু থাকলে মিক্স হয়ে একটা অডিও ট্র্যাকে যায়।
- একসাথে নিলে ইয়ারফোন লাগান, নইলে স্পিকারের সাউন্ড মাইকে আবার ধরা পড়ে ইকো হয়।

## সীমাবদ্ধতা
- যেসব অ্যাপ নিজেরা সাউন্ড ক্যাপচার নিষিদ্ধ করেছে (কিছু স্ট্রিমিং/ব্যাংকিং/কল অ্যাপ) তাদের সাউন্ড আসবে না।
- কিছু অ্যাপ (Netflix ইত্যাদি) DRM-এর কারণে স্ক্রিন কালো দেখায়।
- ভেতরের সাউন্ড মাইকের সাথে মিক্স হয়ে স্টেরিওতে সেভ হয়; আলাদা ট্র্যাক হয় না।
